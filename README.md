# UI Automation Framework

## Project Overview

This project consists of building a professional UI Automation Framework designed to automate web application testing through modern automation tools and software testing practices.

The framework will focus on creating reusable, maintainable, and scalable automated test scenarios.

## Project Objectives

- Develop a structured UI Automation Framework from scratch.
- Automate real-world web application workflows.
- Apply the Page Object Model (POM) design pattern.
- Implement Behavior-Driven Development (BDD) using Cucumber and Gherkin.
- Generate automated test reports and execution evidence.
- Integrate the framework into a CI/CD pipeline.

## Technology Stack

- **Programming Language:** JavaScript
- **Runtime Environment:** Node.js
- **Browser Automation:** Playwright
- **BDD Framework:** Cucumber
- **Scenario Language:** Gherkin
- **Version Control:** Git
- **Repository Management:** GitHub
- **CI/CD:** GitHub Actions

## Testing Scope

This project focuses exclusively on User Interface (UI) automation testing.

The following testing areas are outside the current scope:

- API Testing
- Database Testing
- Backend Testing

## Framework Design Principles

The framework will follow professional software automation practices:

- Page Object Model (POM).
- Reusable methods and components.
- Separation of concerns.
- Readable and maintainable test scenarios.
- Centralized test data management.
- Automated reporting and failure evidence.

## Project Structure

The framework structure will be developed progressively, following a modular and maintainable architecture.

## Continuous Integration

GitHub Actions will be implemented to execute automated scenarios during the CI/CD process and preserve test execution evidence.
